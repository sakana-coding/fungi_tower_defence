# 第三关：自我和解

## 入口与结构

第二关胜利后点击“进入第三关”，观看或跳过CG3后进入；也可在 Godot 打开 `scenes/levels/third_level.tscn` 后按 F6。默认入口为总菜单。

第三关继承 `scenes/gameplay/colony_gameplay.tscn` 与 `ColonyLevelRuntime`。地图和初始组织独立配置；共用建设、供养、回收、成长、分化、修复、移植及资源结算，操作与前两关一致。

| 文件 | 职责 |
| --- | --- |
| `scripts/third_level.gd` | 独立关卡接线、输入、目标与终局 |
| `scripts/memory_fragment.gd` | 碎片身份、文案、进度与占位显示 |
| `scripts/fragment_collection_controller.gd` | 有效覆盖、断路续接、唯一完成事件 |
| `scripts/exploration_production_profile.gd` | 第三关独立五类敌人阶段配比 |
| `scripts/exploration_production_controller.gd` | 分入口持续批次、压力上限、暂停与终止 |
| `scripts/third_level_hud.gd` | 目标详情、结算与CG4文字占位 |
| `scripts/third_level_guide.gd` | 第三关专属首次事件提示 |

## 开局与目标

母核240生命、100养分，三处攻击器官各4点初始库存，一个后方胃囊。四处大型尸骸依次提供80、80、80、120养分。左上、右上、右下碎片开局可见，可按任意顺序收集；三条路线可使用现有连接操作互连。

近处资源支持首次建设，左上资源位于探索途中，右侧提供支路选择，远端120养分资源位于右下碎片之前。2026-10-20精简后，左上、右上、右下碎片分别移至(280,325)、(940,335)、(950,710)，示例路线的前沿建设从2/3/3段缩为1/2/2段，保留三个独立方向与途中资源。地图、位置、初始资源和组织直接在独立场景编辑。

每个碎片的 `fragment_id` 必须非空且唯一；`display_name`、`memory_text` 和 `collection_seconds` 可在对应节点编辑，默认持续收集5秒。`label_offset` 只调整文字相对碎片的位置，避免移近目标后与途中资源标注重叠，不改变收集位置或范围。

收集同时核实 `FungalField.get_collecting_nodes()`、真实可用母核路线与组织功能。多个有效覆盖来源不加速；失联或失去覆盖暂停并保留进度，恢复后继续；灰色残影不收集。已完成目标永久保留，不扣养分、不创建尸体、不进入运输或累计回收。

顶部显示碎片数量，点击打开“碎片与来袭”详情，查看每个目标的进度、等待状态与入口倒计时。碎片地图标记也显示进度。入口在下一批前提供预警。

## 持续出怪

配置文件：`resources/exploration/third_level_production.tres`。与第二关配置隔离，复用既有五类敌人、`EnemySpawnEntry` 和 `EnemySpawner` 的真实身份、批次与死亡回收机制。

| 参数 | 初值 | 作用 |
| --- | --- | --- |
| `preparation_seconds` | 25秒 | 首轮准备 |
| `cycle_seconds` | 40秒 | 每个入口生产周期 |
| `source_stagger_seconds` | 6秒 | 首轮入口错开时间 |
| `warning_seconds` | 5秒 | 来袭预警 |
| `advanced_after_seconds` | 75秒 | 中期时间兜底 |
| `full_after_seconds` | 180秒 | 后期时间兜底 |
| `collection_grace_seconds` | 15秒 | 收集后各入口下一批至少延后至此 |
| `max_alive_per_source` | 6 | 每入口活体与待生成成员总上限 |
| `normal_count` | 1 | 每入口每轮普通敌人数量 |
| `swarm_size` | 1 | 群体批次成员数 |
| `member_interval` | 1.2秒 | 不同条目的生成间隔 |

普通敌人从开局参与。收集一块或到达中期时间后，右上加入1只小型敌人和菌丝啃食者；收集两块或到达后期时间后，右下加入重甲与菌结啃食者，左上交替加入菌丝型。达到第三阶段后维持固定配比与属性，不无限增长。

较晚探索右下时，应先在已有火力内建立前沿据点并完成破甲分化，再继续向下一处种芽。分化期间该器官停火，须保留其他火力掩护。幼芽受袭后若宿主菌结仍在，通过选择该菌结并按C重新培育，继续使用真实供养和已有网络。

每轮独立建批，不等待上一批清空；存活和待出生成员共同占用上限。出生避开障碍、玩家组织、菌丝和碎片附近区域；被堵时延后重试。暂停不生成、恢复不补发。收集事件只调整后续倒计时，不追加同帧大军。

## 胜负、结尾与重开

收齐三个不同ID且母核存活，立即保存结果并停止生产、收集与共用玩法；不等待清敌、成熟或运输。与母核死亡同帧时失败优先，只结算一次。

胜利后先冻结展示网络1.5秒，再打开共用播放器显示CG4“与自己和解”。点击“继续”或跳过后显示通关结果，可重开第三关。图片与帧时长在 `resources/story/cg4.tres` 配置；四段CG均已接入，详见 `docs/CG占位与图片替换说明.md`。

暂停重开与结尾期间重开均重新加载第三关初始场景。旧批次、目标与结尾计时连接随旧场景退出清理，不影响新局。
