# 屏幕适配（2026-10-20）

窗口与全屏由全局 `GameDisplay` 管理。场景只声明逻辑画布尺寸，避免进入关卡时覆盖玩家选择的窗口大小。标题保留1200×800逻辑画布，关内保留1200×920；实际窗口按屏幕缩放，宽高比差异使用 `canvas_items + expand` 补足画布，图片不做非等比拉伸。

## 玩家操作

- 标题页左下角、关内暂停菜单提供窗口／无边框全屏切换。
- F11 或 Alt+Enter 在标题、剧情、关内、暂停和结算时都可切换。
- 窗口大小、位置、最大化与全屏选择保存于 `user://display_preferences.cfg`，与音量和关卡进度分开。
- 首次窗口按当前屏幕可用区域缩小；切关、重开和返回标题不会恢复固定物理尺寸。
- 原有WASD、中键、滚轮和Home镜头操作保留。

## 工程入口

| 文件 | 职责 |
| --- | --- |
| `scripts/display/game_display.gd` | 自启动显示管理器，负责窗口、全屏、快捷键、设置保存和显示器变化 |
| `scenes/ui/display_settings_control.tscn` | 标题与暂停共用的显示设置控件 |
| `scripts/display/display_settings_control.gd` | 只提交切换意图并刷新按钮文字 |
| `scripts/gameplay/colony_camera.gd` | 使用独立的世界坐标开局焦点，限制平移，保持鼠标锚点缩放 |
| `scripts/visuals/map_boundary.gd` | 绘制可生长范围的淡铅笔虚线；G/B/L模式中显示说明 |
| `scenes/gameplay/colony_gameplay.tscn` | 场景中显式放置MapBoundary节点与说明Label |

新增场景若需要设置逻辑画布，调用 `GameDisplayManager.ensure(get_tree()).configure_canvas()`；不要在关卡中设置 `get_window().size`。CG与暂停层通过 `GameDisplayManager.is_display_shortcut(event)` 放行全局显示快捷键，避免误推进剧情或触发菜单选择。

地图坐标、可建造范围、射程、移动速度和运输距离均未改变。三关镜头边界收紧到 `Rect2(-120, -80, 1440, 1080)`；开局与复位焦点为世界坐标 `(600,460)`。视野比边界更宽时居中，纸面继续覆盖可见区域。地图扩建需要单独做关卡设计。

界面沿用现有手绘素材。窄比例时顶部区域可分行，详情页可滚动；建造说明固定在左下角，让地图中央保持可见。暂停菜单增加滚动容器，剧情底部使用可换行的按钮容器。

## 验证

- `tests/colony_camera_test.gd`：217项通过，覆盖三关输入、缩放、暂停规划、建造与宽屏边界。
- `tests/ui_display_adaptation_test.gd`：387项通过，覆盖三关七种尺寸、帮助页、建造提示、暂停菜单与剧情快捷键。
- 现有主菜单与章节进度验收57项通过。
- 实际OpenGL窗口集成45项通过；另外验证首次尺寸适配、最大化往返、退出后重启恢复设置。
- 实际渲染检查1280×720、1366×768、1920×1080、2560×1440、1280×1024、1920×1200及2560×1080，检查标题、剧情、三关、建造、帮助、暂停与结算。结算画面使用测试伤害夹具，不作为正常规则通关证明。

自动化测试可在启动前设置 `FUNGI_DISPLAY_PREFERENCES` 为独立配置文件路径，避免覆盖玩家显示选择。无头模式不读写真实窗口设置。上述验证在当前Windows电脑完成，尚未替代导出包在另一台电脑上的运行检查。现有菜单测试仍有音频资源退出清理提示，本次未新增该问题。
